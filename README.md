# spry-grove

Data engineer · Scala and Spark

给自己省点事的小工具

## 用法

```bash
cat data.txt | node index.js
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/spry-grove.git
cd spry-grove
npm install
```

## 备注

就是给自己省点事，没做太多抽象。
